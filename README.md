## `whoami`

Je suis **Rahman YILMAZ**, développeur **full-stack freelance** basé à **Chalon-sur-Saône**, disponible en **remote** ou en **Bourgogne / France**.

J’aide les startups, agences et PME à transformer un besoin métier en **produit utile, maintenable et livrable** : prototype SaaS, dashboard client, outil interne, application desktop, pipeline data/IA, intégration paiement, reprise de code ou MVP.

- 🎓 **Bac+5** — Bases de Données & Intelligence Artificielle  
- 🧩 **Produit** — cadrage, UI, API, données, déploiement, maintenance  
- ⚙️ **Stack terrain** — SvelteKit, TypeScript, Rust, Tauri, Node.js, PostgreSQL, Docker  
- 🧠 **Data & IA** — pipelines LLM, indexation documentaire, ETL, recherche, exports  
- 🤝 **Formats** — forfait, TJM, mission courte, audit technique, renfort agence
